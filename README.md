# A Day of One-Line Pitches — v3

One sentence, at most 240 characters, that convinces a friend who has never
coded to let an AI agent build their first app idea on
[make.fun](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3).

`main.ts` writes the pitch to `$OUTPUT_DIR/entry.txt` (default `/output`),
checking it is one line of 1–240 characters first. Node 22, standard library
only, no network.
